
# Healthcare Patient & Encounter Analytics

## Project Overview

This project analyzes healthcare patient and encounter data to identify healthcare utilization patterns, claim costs, demographic trends, and data quality issues.

Using MySQL, Microsoft Excel, Python, and Power BI, I performed data preparation, exploratory analysis, statistical analysis, and dashboard development to support data-driven healthcare decision-making.

The project demonstrates an end-to-end healthcare analytics workflow, from data validation and SQL querying to business intelligence reporting.

## Tools and Technologies

- **MySQL:** Data extraction, joins, data validation, NULL handling, and aggregation
- **Microsoft Excel:** Data cleaning, validation, and exploratory analysis
- **Python:** Statistical analysis and exploratory data analysis
- **Power BI:** Interactive dashboards, DAX measures, KPI cards, slicers, and visualizations

## Dataset Overview

The project uses synthetic healthcare records containing:

- **108 patients**
- **5,571 healthcare encounters**
- Patient demographics, encounter characteristics, healthcare utilization, and claim costs

The dataset was analyzed to understand patient encounter patterns and evaluate healthcare costs across encounter types.

## Project Methodology

### 1. Data Cleaning and Validation
- Examined missing values and inconsistent data.
- Validated patient and encounter records.
- Reviewed date fields and data quality.
- Identified incomplete encounter reason descriptions.

### 2. SQL Analysis
- Used MySQL to analyze patient and encounter datasets.
- Performed joins to combine patient demographics with encounter information.
- Applied filtering, grouping, and aggregation techniques.
- Calculated utilization and claim cost metrics.

### 3. Excel Analysis
- Reviewed healthcare encounter data using Excel.
- Performed data validation and summary analysis.
- Supported interpretation of healthcare utilization and cost metrics.

### 4. Python Statistical Analysis
- Conducted additional exploratory and statistical analysis using Python.
- Examined relationships and patterns in healthcare encounter data.
- Investigated distributions and potential outliers.

### 5. Power BI Dashboard Development
- Built an interactive healthcare analytics dashboard.
- Created DAX measures and KPI visualizations.
- Developed charts to examine claim costs and encounter utilization.
- Added interactive filters and slicers to support data exploration.

## Key Findings

| Metric | Result |
|---|---|
| Total Patients | 108 |
| Total Encounters | 5,571 |
| Total Claim Costs | Approximately $16.81 million |
| Ambulatory Encounters | 2,939 |
| Ambulatory Claim Costs | Approximately $12.82 million |
| Encounters With Missing Reason Descriptions | 2,044 (36.7%) |

### Business Insights

- Ambulatory care accounted for the largest share of healthcare encounter utilization and claim costs.
- Encounter-level analysis revealed differences in healthcare utilization across service categories.
- Missing reason descriptions were identified as a significant data quality issue.
- Interactive reporting helped organize healthcare utilization and financial metrics into a format suitable for decision-making.
