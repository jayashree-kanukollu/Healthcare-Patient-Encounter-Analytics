# Healthcare Patient & Encounter Analytics

## Project Overview
Analyzed healthcare patient and encounter data to evaluate utilization patterns, claim costs, data quality, and operational performance.

This project combines SQL, Excel, Python, and Power BI to demonstrate an end-to-end healthcare analytics workflow.

## Tools and Technologies
- MySQL — Data extraction, joins, validation, and cleaning
- Microsoft Excel — Data exploration and validation
- Power BI — Interactive dashboard development and DAX
- Python — Exploratory and statistical analysis

## Dataset
- 108 synthetic patients
- 5,571 healthcare encounters
- Patient demographics, encounter characteristics, and claim costs

## Methodology
1. Imported and explored patient and encounter datasets.
2. Used SQL joins to connect patient and encounter information.
3. Checked missing values, dates, and data consistency.
4. Analyzed healthcare utilization and claim costs.
5. Developed Power BI dashboards with KPI cards, slicers, and trend visualizations.
6. Conducted additional exploratory analysis using Python.

## Key Findings
- Analyzed 5,571 encounters across 108 synthetic patients.
- Total recorded claim costs were approximately $16.81 million.
- Ambulatory care accounted for 2,939 encounters and approximately $12.82 million in claim costs.
- Identified 2,044 encounters (36.7%) with missing reason descriptions, highlighting a data-quality improvement opportunity.

## Dashboard Features
- Healthcare utilization KPIs
- Claim cost analysis
- Encounter-type comparisons
- Patient demographic analysis
- Interactive filtering and visualizations

Demonstrate healthcare analytics skills in SQL, Excel, Power BI, Python, data validation, and business intelligence reporting.
